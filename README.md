# trabajo01grupotd2026
En este repositorio se encuentran los enunciados y soluciones de los problemas de Teoría de la Decisión bajo Incertidumbre de todos los integrantes del grupo, que son: Daniel Gallego Cortés, Daniel Hernández Utrilla, Enrique León Ruiz. Nos organizamos realizando creando un grupo de Whatsapp donde comentar algunas que surgieron realizando cada uno su parte individual, y poniendo una fecha común para la realización de la parte grupal de manera conjunta, para llevarlo todos más o menos al mismo tiempo.

Además de en formato pdf y html, se encuentra el documento qmd que se ha usado para conseguir los otros dos, tanto el de los enunciados como el de las soluciones.
Por último, el archivo teoriadecision_funciones_incertidumbre.R son funciones necesarias para la ejecución del archivo qmd de soluciones.
